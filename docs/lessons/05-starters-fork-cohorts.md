# A starter change forks a new cohort; it never edits a registered card.
Rule: v1 stays immutable; each new tier-1 starter attestation forks v2/v3/... registered pre-start. Absence of information is not a starter change (no fork on silence). Unresolvable conflicts stay blocked and the true starter is attributed at settlement, never retro-edited.
Evidence: starter resolution moves win probabilities ~2-3pp on average, ~5x form freshness (8/17-8/19 measurements).
