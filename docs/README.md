## Historical material is not a current status feed

`progress.md`, `history/`, dated release/research reports, `dashboard.html`, `core_breakdown.html` and `model_breakdown.html` contain retained checkpoints. Their old model names, pending actions, dates or eligibility statements do not establish the current repository state. They are not silently rewritten to make past work look current or successful.

The [pre-refresh guides](history/2026-10-23-status-refresh/) preserve exact original blobs. The current status page reconciles subsequent integration without changing original research results, signed records, machine policy or approval requirements. Open-branch documentation must be read at its exact PR head.
