# Never invent a number: unknown = null + flag (R1).
Rule: illegible cells, unregistered pitchers, missing lines all record as null with a reason. League-average CAP is a declared substitution inside the sim, never a fabricated stat. R1 binds the report layer too (see lesson 02).
Extension (2026-08-21): the same principle governs GATES, not just data. When a genuinely unfinished game turned the slate-completeness check red, the wrong fixes were (a) invent a result and (b) relax the check. The right fix was a narrower predicate: excuse the game only when an explicit entry names it, states a reason, and is fresh — and make the excuse EXPIRE (36h) so a missing result cannot hide behind a stale note. A pending state is real and deserves representation; an open-ended exemption is not.
