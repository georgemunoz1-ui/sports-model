# A predicted margin is not a betting spread — render it with the team, the direction in words, and the negated fair spread.
Rule: home_margin_pred = home points - away points. NEGATIVE means the HOME team LOSES. The fair home spread is the NEGATION. Never print the raw signed margin in spread notation; print "TEAM projected to lose by X (fair spread TEAM +X)".
