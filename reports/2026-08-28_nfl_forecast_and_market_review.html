Why the ids are here at all

These rows produce no forecast, so the ids buy nothing tonight. They are retained because a future binding pass needs a real key to verify against, and because capturing them proved something worth recording: the ids are not ordered by kickoff and do not occupy one block. Inside the 4018733xx run the mapping is 301 = CIN@PHI (8:00), 302 = WSH@BAL (6:00), 303 = NYG@NYJ (7:30), 304 = ATL@MIA (7:00), 305 = SEA@KC (8:00), 306 = TB@JAX (7:30), 307 = HOU@CAR (7:00). Sorting by kickoff and assigning sequentially — the natural shortcut — would have mis-assigned every single row. Three more games sit entirely outside that block. Each id was captured from its own game page.

One row carries a resolved contradiction: NYG@NYJ. One enumeration pass rendered it “Jets at Giants”; three independent sources put the Giants away. A reversed home and away is the same class of error as a reversed starter, so it is marked rather than quietly settled.
