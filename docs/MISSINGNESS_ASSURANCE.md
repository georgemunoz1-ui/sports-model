## Reading a receipt

Look for the model/arm, event, target, source state, input snapshot and forecast binding. Read the sport-specific explanation in the receipt. A verified empty input requires evidence of coverage. Partial identity, source failure, and team-history defaults remain explicit. A retained previous edition enables paired change attribution. A missing prior leaves that comparison unavailable.

Linear contributions use margin/total units and log odds for the logistic winner head. Compare fitted heads and numerical laws independently of random draws. A nonlinear mixed-input comparison requires supported counterfactual inputs, a declared order, and an interaction term where applicable. Sensitivity experiments do not establish player value or give permission to change the live forecast.

## Release and statistical evidence

The signed validation registry reads the missingness policy and evaluation by content ID. The policy fixes the procedure, target, source/season strata, model-unit limits, calibration sample and monitoring population before confirmation. Group comparisons use the same events as their incumbent and independent comparators. The gate recomputes Brier, log loss, absolute or squared error under the registered scoring rule. Signed registrations and reconciled results bind event identity, forecast, observation time and outcome. Each of the seven engineering test classes needs an evidence object.

The current release manifest, promotion check and board-readiness check also require a protected, independently reviewed scope. Each complete event must match the witnessed release inventory and the current source measurements. A missing approval, unsigned empty schedule, changed product/settlement, missing receipt or unsupported observation blocks the affected claim. Historical v1 release artifacts have a read-only verification path.

The approval index starts empty. The presence of a receipt, a numerical perturbation, a passing software test, a draft PR or a correct game call does not fill it. Production branch protection, independent review signers, their authorized observations, sustained forward monitoring and product-specific statistical approval are separate operational requirements.

## Cincinnati at Atlanta regression

The combined model's original two-missing-team state falls outside its observed training support. The frozen fit contains 2,877 games with zero reports missing, eight with one missing and zero with two missing. Supplying both reports moved the fitted margin 8.01 points toward Cincinnati through the reporting indicator. The other changes collectively moved it 1.12 points toward Atlanta. The refreshed QB arm consumed none of those non-QB inputs.

The isolated NFL candidate limits the reporting count used by each fitted arm to that arm's earlier training support. It keeps the true observed count in the audit. Seven expanding-year fits for each arm produced 1,871 same-game historical comparisons per arm, including 1,865 decisive winners. Zero held-out games activated the intervention.
