# Before crediting a win-loss record, compute what the dumbest base-rate strategy would have scored on the same slate.
Rule: a record is only meaningful against the base rate it was drawn from. Always report the trivial benchmark (always-home, always-favorite) alongside any cohort record, and split the record by pick direction — a model that is 10-1 picking home and 0-4 picking away has not demonstrated discrimination, it has ridden a base rate.
Incident: 2026-08-21 MLB. I reported v2 at 10-5 with a 6.1% Brier improvement over v1 and called it the first clean starter-information measurement. The owner pointed out home teams went 14-1 that night and that v2 was 10-1 on home picks, 0-4 on away. Verified: BOTH cohorts went 0-for on every away pick, and an always-pick-home heuristic would have gone 14-1 — beating v2 by four games. The Brier still beat a flat 50%, so the probabilities held some information, but the win-loss headline was worse than the crudest possible strategy and I had presented it as the slate's achievement.
Companion: this does not invalidate a v1-vs-v2 comparison (the base rate is common to both cohorts), but it does qualify the flips — three of v2's four gains were flips toward the home side on a 14-1 home night, so the same information could have flipped them the other way on a different slate.
