# Rank the misses by confidence before calling them noise — a compressed model can still be most-confident and most-wrong on the same game.
Rule: never describe a set of errors as "the least confident calls" without computing |p-0.5| and ranking them. Compression is a property of the whole distribution; it does not tell you where in that distribution the errors landed.
Incident: 2026-08-20 MLB. The assistant reported all three misses as "coin flips... the model's least decisive calls." Ranked, the misses were #1 of 8 (LAA@HOU, p_home .560, the slate's MOST confident registered forecast and its worst Brier at .3136), #3 of 8 (WSH@TEX), and #8 of 8 (TOR@TB). Owner caught it. The withdrawn wording made the errors sound structurally excusable; the true picture is worse for the model.
Companion rule: a card row generated after its own first pitch is a post-start display, never a "pregame projection" — check the artifact's generated_at against each game's start time before applying a pregame label to a whole table (STL@CIN, card built 16:43:29Z, first pitch 16:40Z).
